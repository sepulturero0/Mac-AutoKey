# Mac AutoKey interface

Mac AutoKey is a restrained native macOS utility. Use system typography, SF Symbols, native controls and system light/dark appearance. The user explicitly requested a friendlier interface; version 1.2 reorganizes the existing clicker and keyboard features around everyday tasks.

## Layout

The default window is 940 × 760 points, with a minimum content size of 860 × 650. A compact header contains the product name, current state, access status, Settings, and Stop All. A native segmented control switches between Auto Clicker and Keyboard Commands. A fixed bottom run bar contains the selected command or click task, countdown guidance, the primary Start/Run or Stop control, save notice, and shortcut. It remains visible while long content scrolls.

Keyboard Commands uses a native split view. The resizable sidebar shows names, shortcuts, step counts, and enabled state, plus the global keyboard-shortcuts toggle. Add Command, Duplicate, Delete and Undo Delete stay at the bottom. The editor scrolls independently and presents the command name, enable switch, shortcut, then ordered steps. Add Step offers text, key, and wait actions directly. Each step has a stable number and an options menu for reordering/deletion. Text grows to multiple lines. Typing mode and inter-key timing live under Typing options.

Auto Clicker presents an enable switch, explicit time-between-clicks field with units and presets, approximate clicks per second, and a clearly named start/stop shortcut. Named Command/Option/Control/Shift checkboxes avoid requiring users to know modifier symbols.

Settings contains Accessibility onboarding, optional Citrix target restrictions, and troubleshooting. Granted access is compact in the main window; denied access exposes Set Up Access. Validation and runtime errors stay visible above the workspace; a resolved runtime error can be dismissed. Disabled Run controls have a nearby explanation. Empty commands provide a direct next action.

## Native system

- Typography: system title2 for the product, title3/headline for task/field groups, body/callout for editing and labels, caption for helper text. Monospaced digits and shortcuts only where useful.
- Color: native surfaces, primary and secondary text, system tint for primary actions, green access status, orange warnings, red errors and active Stop. Color always accompanies text or an icon.
- Spacing: 20 pt header/run bar, 24 pt editor margins, 10–16 pt related control gaps, 22–24 pt major groups. No decorative animation, imagery, custom fonts or network assets.
- Accessibility: native lists, splitters, pickers, switches and text fields; persistent field labels; explicit labels/help for icon actions. Reordering does not require dragging. Standard Command+comma opens Settings. Stop All remains available in the window and menu bar.
- Safety: no automation on launch; manual starts hide the utility and allow three seconds to focus a target. Input remains bound to the target PID. All valid edits autosave; invalid numeric drafts remain visible. Deleting a command supports one-level Undo Delete, preserving its content and selecting a free shortcut if necessary.

The app icon is an authored geometric cursor graphic generated by Scripts/make-icon.swift using AppKit.

## Version 1.3 status states

A compact labeled status indicator appears beneath the title, with green Running, amber Paused, gray Stopped, blue Starting, and red Error. Sidebar dots use the same state color and active commands also show a state label. The menu bar uses the matching state symbol/color and exposes Pause/Resume without bringing the configuration window forward. Paused runs can be inspected without losing their original target; the fixed run bar offers Resume and Stop. Manual Resume provides three seconds to restore the original target. No blinking, pulsing, or color-only meaning is used.

As of version 1.5.2, the menu bar icon starts, pauses, and resumes the Auto Clicker. It shows green play while running and red pause while paused. Right-click or Control-click opens the options menu. Start and Resume give the user three seconds to move their pointer to the target. Generated pointer clicks skip the menu bar and the app suspends generated clicks while its status menu is open. The window status indicator still uses amber for paused.

## Version 1.4 fullscreen layout

The workspace is centered and bounded at 1,240 pt for Keyboard Commands and 940 pt for Auto Clicker. The native window and background still fill fullscreen. The header, workspace, and fixed run bar share the same outer edges, keeping primary actions within reach rather than stretching them to the screen corners. The keyboard editor content is capped at 900 pt and aligned to the leading edge of its pane; the resizable command sidebar keeps its existing limits. Default and minimum window sizes remain 940 × 760 and 860 × 650. Scrollable content consumes remaining height while command-management and run controls stay visible.

## Version 1.5 fixed click position

Auto Clicker places Fixed click position immediately below its introduction. The native switch defaults off, preserving pointer-following clicks. Enabled mode exposes labeled X/Y integer fields and Pick Position (3s), which captures coordinates without clicking; its countdown can be cancelled. Coordinates are global screen points, with a top-left origin on the main display and signed values for other displays. The run bar names the saved position. All settings autosave. Changing settings, changing applications, or losing the target stops the run. The pointer stays free; there is no cursor hiding, locking, warping, or restore jump in this mode. Clicker content scrolls in shorter windows while the run bar stays visible.
